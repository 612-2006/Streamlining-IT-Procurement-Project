# Streamlining IT Procurement Project - ServiceNow

This project automates the IT Laptop Procurement process using ServiceNow Service Catalog and Flow Designer.

## Problem Statement
In IT companies, laptop procurement is manual via emails. It causes delay and no tracking.

## Solution
Created a Service Catalog Item "Standard Laptop Order" and automated the approval and fulfillment using Flow Designer.

## Workflow
User -> Orders in Service Portal -> REQ Created -> Manager Approval via Flow -> IT Team gets SCTASK -> Request Closed
